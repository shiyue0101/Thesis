# Thesis-Arduino-Codes
The server for the master thesis, including Arduino codes and the link to the server repository.

## Arduino Codes
- `forceOnly_test`: Arduino code for the force sensor only, which can send text message to Discord according to different force values.
- `microphoneOnly_test`: Arduino code for the microphone only, which can send text message to Discord according to different sound levels.
